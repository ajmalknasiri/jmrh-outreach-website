# Admin Guide — Updating the JMRH 29:11 Outreach Website

This guide is for team members who keep the website up to date. No coding needed.

## Logging in
Go to **yoursite.org/admin** and log in with the account you were invited to. (Ask the site manager for an invite if you don't have one.)

## Add a new resource
1. Click **Resource Directory → Resources**.
2. Scroll to the bottom of the list and click **Add Resource**.
3. Fill in the fields:
   - **ID:** a short name with dashes, like `hayward-food-pantry`. Never change it later.
   - **Show on website:** leave on.
   - **Area** and **Types of help:** pick from the lists. Choose every type that applies.
   - **Short description:** 1–2 plain sentences. End with a reminder like "Call to confirm hours."
   - **Location type:**
     - *Fixed address* → shows a Directions button
     - *Phone-based* → no address needed
     - *Mobile / rotating* → shows a "locations rotate" notice
   - **Phone:** digits only, like `5105551234`.
   - **Website:** full link starting with `https://` (or leave blank).
   - **Last verified:** today's date, if you called to confirm.
4. Update **Data version** at the top to today's date.
5. Click **Save**, then **Set status → Ready**, then **Publish**. The live site updates in about a minute.

## Fix or update a listing
Open **Resources**, click the listing, change what's needed, set **Last verified** to today, and Save → Publish.

## Hide an outdated listing
Turn off **Show on website**. The listing stays saved so you can turn it back on later. (Only delete a listing if it's gone for good.)

## Handling suggestions from the public
Suggestions sent through "Suggest or update a resource" arrive by email. **Nothing is published automatically.** Before adding or changing a listing:
1. Call the organization to confirm the address, phone number, and services.
2. Only add details you confirmed. Don't guess hours or eligibility.
3. Set **Last verified** to the date you checked.

## Good habits
- Re-check every listing by phone every few months and update **Last verified**.
- Keep descriptions short and in plain language.
- Never write that a service is "open now" or "always available."

## Changing page text, the logo, or contact email
These need a small edit to the website files. Ask the site manager, or see "Changing other things" in `README.md`.
